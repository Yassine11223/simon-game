# Simon Game

A browser-based Simon Game built as part of **The Complete 2026 Web Development Bootcamp by Angela Yu**.

## About

The game challenges the player to remember and repeat an increasingly long sequence of colors.

This project was built while practicing **JavaScript, jQuery, DOM manipulation, event handling, and game logic**.

## Technologies

* HTML
* CSS
* JavaScript
* jQuery

## Features

* Random color sequences
* Increasing difficulty with each level
* User input validation
* Sound effects
* Button animations
* Game-over detection
* Keyboard controls

## What I Learned

* Working with JavaScript functions and arrays
* Generating random values
* Manipulating HTML elements with JavaScript and jQuery
* Handling keyboard and mouse events
* Managing game state and sequences
* Using Git and GitHub for version control
